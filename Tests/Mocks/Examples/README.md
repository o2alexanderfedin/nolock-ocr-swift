# Mockingbird Examples

This directory contains example files showing how Mockingbird could be used for testing the NolockOCR package.
These files are not included in the test target and are for reference only.

## Content

- `MockingbirdExample.swift` - Shows how to use Mockingbird to create mocks for OCRProcessingService tests

## Status

These examples are currently not used in the CI/CD pipeline and are excluded from compilation.
They are provided as reference for future implementation of Mockingbird-based testing.
